# Have You Tried Turning It Off?

One funny line from a hopeless tech support agent to a desperate customer: a frozen computer reframed as meditation, with the agent cheerfully admitting the machine is coping better than he is.

## Run

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (UTF-8, one line, under 200 characters). Python 3.13 standard library only; no network at run time.
